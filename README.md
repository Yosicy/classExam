ClassExam

AI-Powered Competitive Examination Platform

ClassExam is an educational platform designed to help students prepare for competitive examinations through interactive tests, challenging questions, and AI-powered learning support.

Subjects

- Mathematics
- Biology
- English
- Physics
- Chemistry
- Aptitude

Planned Features

- Timed examinations
- Multiple-choice questions (A–E)
- Automatic marking and scoring
- Student accounts and invitation-only access
- Class leaderboard and rankings
- AI-generated questions
- AI-powered answer explanations
- Performance analysis and study recommendations

Academic Coverage

- Ethiopian Grades 9–12
- University Entrance Examination (UEE)
- Model examinations and practice tests

Question Quality

Questions will be reviewed by an administrator before publication. Educational sources will be acknowledged where applicable.

Project Status

Currently under development.
